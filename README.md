# Portfolio + Resume (React, Vercel)

Built with React and Vite. Deployed 100% natively on Vercel with Vercel Blob storage.

- **Portfolio:** `/`
- **Resume:** `/resume`
- **Admin Dashboard:** `/admin` (Default Admin Key: `123`)

### Live Cloud Autosave
Edits made in `/admin` autosave directly to **Vercel Blob** and are read back instantly. Changes appear live for all visitors immediately without redeploying.
